== Part 2: the incident's three records, parsed from the Security log ==
Source: a copy of the client's Security log taken on October 1, 2026 (the log file itself is
not published), parsed October 2, 2026 with python-evtx 0.8.1 and the script below.
TimeCreated is printed from the raw FILETIME value (100-nanosecond intervals since 1601-01-01
UTC) with all seven fractional digits; python-evtx's own printed time stops at microseconds
and, for these records, differs from the raw value by up to 2 microseconds. Values are replaced
as in Part 1.

$ shasum -a 256 Security-2026-10-01.evtx
5fbc2617e20ed77f80b9b0e64c180234ab1bd2bc7208978fa8dbdbd068537d9e  Security-2026-10-01.evtx

$ cat parse_security_records.py
import sys, datetime, xml.etree.ElementTree as ET
import Evtx.Evtx as evtx, Evtx.Nodes as N
NS = '{http://schemas.microsoft.com/win/2004/08/events/event}'
want = {int(x) for x in sys.argv[2].split(',')}
print('%-8s %-7s %-29s %-19s %-9s %-18s %-15s %-48s %s' % ('RecordID', 'EventID', 'TimeCreated (UTC, 100-ns)', 'FILETIME', 'Subject', 'LogonId', 'Target', 'TargetSid', 'MemberSid / Caller'))
with evtx.Evtx(sys.argv[1]) as log:
    for rec in log.records():
        if rec.record_num() not in want:
            continue
        root = ET.fromstring(rec.xml())
        shown = root.find(NS + 'System/' + NS + 'TimeCreated').get('SystemTime')
        # raw FILETIME behind TimeCreated; python-evtx's own print stops at microseconds
        ft = [s.unpack_qword(0) for s in rec.root().substitutions()
              if isinstance(s, N.FiletimeTypeNode) and s.string() == shown][0]
        sec, ticks = divmod(ft, 10**7)
        utc = (datetime.datetime(1601, 1, 1) + datetime.timedelta(seconds=sec)).strftime('%Y-%m-%dT%H:%M:%S') + '.%07dZ' % ticks
        d = {e.get('Name'): e.text for e in root.find(NS + 'EventData')}
        print('%-8s %-7s %-29s %-19s %-9s %-18s %-15s %-48s %s' % (rec.record_num(), root.find(NS + 'System/' + NS + 'EventID').text, utc, ft,
              d.get('SubjectUserName'), d.get('SubjectLogonId'), d.get('TargetUserName'), d.get('TargetSid'), d.get('MemberSid') or d.get('CallerProcessName') or '-'))
